# デュエマ デッキ管理・サポートアプリ

身内向けを前提にしつつ、デュエル・マスターズを遊ぶ・管理する・判断する・改善するための総合サポートアプリを目指す。

## 開発方針

- 効率より正確性を優先する
- 公式情報を基準にする
- AIに裁定やカード情報を勝手に作らせない
- カード情報・裁定・対戦履歴・デッキ変更履歴を分離して管理する
- 将来のAI対戦、ジャッジAI、デッキ改善AIへつながる形でVer.1から土台を作る
- 新機能は開発者同士で相談し、入れるか・どのVer.に入れるかを決める

開発者管理情報：

- データ確認日

### デッキ管理

  - 特殊な構築条件

### 1人回し

### Ver.1終盤：アプリ内ヘルス監視・不具合検知AIの基盤

アプリ内で発生するバグや不具合をできるだけ早く発見できるよう、Ver.1終盤から監視基盤を入れる。

- JavaScriptエラーの記録
- 未処理Promiseエラーの記録
- API / fetch失敗の記録
- Firebase Authentication / Firestoreエラーの記録
- IndexedDB / localStorageの保存・読み込み失敗の記録
- 画面遷移や主要操作が正常に完了したかのヘルスチェック
- カードDB読み込み・検証失敗の検知
- 重大度（情報 / 警告 / エラー / 致命的）の分類
- 発生日時、アプリVer.、端末・ブラウザ情報、発生画面、操作状況を可能な範囲で記録
- 個人情報やパスワードなどの機密情報はログへ保存しない
- 同じ不具合の重複をまとめる
- AIがログを整理し、原因候補・影響範囲・再現手順候補・修正候補を開発者向けに提示
- 必要に応じてGitHub Issue候補へ変換できる構造

「常時監視」は、利用端末側ではアプリが開いている間の監視を基本とする。将来はサーバー側の監視も組み合わせ、アプリが閉じていてもクラウド側で発生した異常やサービス障害を検知できる構成へ拡張する。

AIが本番コードを無確認で自動修正・自動反映する設計にはせず、まず検知・整理・修正案作成を担当し、実際の変更はテストと確認を通す。

## Ver.2

最終目標：不快感のない良い対戦を作る。

- AI対戦
- 環境デッキ
- 必要に応じてモチーフデッキ
- 正確なゲーム進行
- 対戦結果保存
- ジャッジAI

### ジャッジAI

ゲーム状態、カードデータ、基本ルール、裁定DB、公式出典を使って判断する。

根拠を確認できない場合は、推測で裁定を作らず「公式裁定を確認できない」と返せる設計にする。

## Ver.2.5

- 指定ユーザーへの公開
- ユーザー管理
- 公開範囲管理
- 新カード対応
- 新カードを確認次第カードDBへ追加
- 重複・欠損確認
- 将来的な新カード追加支援の下地

### 完全カードDB・高級版 / 特殊仕様対応

同じカード名でも、通常版と高級版・特殊仕様を別の「版」として管理できるようにする。

- 通常版
- 神アート
- 金トレジャーを含む各種トレジャー
- プロモ
- シークレットなどの特殊レア仕様
- イラスト違い
- ホイル / 加工違い
- 再録版
- 収録弾・商品
- カード番号
- 同名カード同士の紐付け
- ルール上の同一カード判定と、版情報を分離して管理

### コレクション・デッキ表示連携

- 所持カード / 所持枚数の管理
- 所持している版の管理
- お気に入り版の設定
- 未所持版の確認
- 同一カードの版違い一覧
- デッキ内でどの版を使用しているか指定
- 通常版2枚 + 神アート1枚 + 金トレジャー1枚のような混在構成に対応
- デッキ内容そのものと見た目・版指定を分離して管理

### カード検索・表示

- 通常版を含むすべての版を表示
- 神アートのみ表示
- トレジャー系のみ表示
- プロモのみ表示
- 高レア / 高級仕様のみ表示
- 同名カードから版違いへ移動できるUI

将来的には、所持カードだけでデッキの見た目を整えたり、高級版中心の構成を提案するAI機能にも接続できる設計にする。

### CS大会結果・入賞デッキDB

CSなどの大会結果を蓄積し、優勝・入賞したデッキを検索・閲覧できるようにする。

- 大会名
- 開催日
- 開催地域 / 会場
- 参加人数（確認できる場合）
- 順位
  - 優勝
  - 準優勝
  - ベスト4
  - ベスト8など
- 使用デッキ / デッキタイプ
- 公開されているデッキリスト
- プレイヤー名（公開情報として確認できるもののみ）
- 結果・デッキ情報の出典
- データ確認日
- 最終更新日
- 情報の確認状態

大会結果はカードDB・デッキDBと紐付け、同じカードを重複登録しない構造を目指す。

検索・表示では、時期・大会・順位・デッキタイプ・カード採用などから絞り込めるようにする。

Ver.3ではこのCS結果DBを環境分析・デッキ改善AIにも利用し、時期ごとの入賞数、デッキタイプの推移、カード採用傾向などを分析できるようにする。ただし、出典が確認できない情報をAIが事実として補完しない。

## Ver.3

最終目標：対戦結果を使って、より良い対戦ができるデッキへ改善する。

- 対戦結果分析
- 弱点分析
- カード変更提案
- カード入れ替え
- デッキ方向性提案
- 変更前後の比較
- 勝てるところまで調整を繰り返す
- デッキ変更履歴と対戦結果を関連付ける
- CS大会結果DBを利用した環境分析
- 時期別の入賞デッキ傾向分析
- カード採用傾向の分析

## バグ・不具合対応AI

Ver.1終盤で入れる監視基盤を育て、Ver.3までにバグや不具合へ素早く対応できるAIへ発展させる。

- 不具合検出
- エラー確認
- 原因特定
- 影響範囲確認
- 修正案作成
- 修正後の動作確認
- 必要なら再修正

## 現在の最優先事項

1. 全カード対応できるカードDB基盤を作る
2. カード情報の正確性を確認する
3. 全カード検索・表示を安定させる
4. レッドゾーン関連5枚で基準テストを行う
5. その後、Ver.1の1人回しへ進む

## 最終的な方向性

単なるデッキ管理アプリではなく、

- カードを調べる
- デッキを作る
- ルールや裁定を確認する
- 1人回しをする
- AIと対戦する
- CSなどの大会結果・入賞デッキを調べる
- 対戦結果を分析する
- デッキを改善する
- バグや不具合を素早く検知・整理・修正する

ところまで支援する、デュエル・マスターズ総合サポートアプリを目指す。

# デュエマ デッキ管理・サポートアプリ

身内向けを前提にしつつ、デュエル・マスターズを遊ぶ・管理する・判断する・改善するための総合サポートアプリを目指す。

## 開発方針

- 効率より正確性を優先する
- 公式情報を基準にする
- AIに裁定やカード情報を勝手に作らせない
- カード情報・裁定・対戦履歴・デッキ変更履歴を分離して管理する
- 将来のAI対戦、ジャッジAI、デッキ改善AIへつながる形でVer.1から土台を作る
- 新機能は開発者同士で相談し、入れるか・どのVer.に入れるかを決める

## Ver.1

最終目標：1人回しまで完成させる。

### カードDB
- 全カード対応
- カード検索
- カード詳細
- デッキへの追加・削除
- 正確なカード情報管理
- 重複・欠損チェック
- カードDB異常検出
- 基準テストデータとしてレッドゾーン関連5枚を使用

### カード情報
ユーザー向け情報：
- カード名
- 文明
- コスト
- 種類
- 種族
- パワー
- 能力テキスト
- カード番号

開発者管理情報：
- 固有ID
- AI用データ
- データ確認元
- データ確認日
- 確認状態（確認済み / 要確認 / 裁定確認待ち など）

### デッキ管理
- デッキ作成・編集・削除
- 40枚管理
- カード枚数管理
- Firestore保存・読み込み
- デッキ合法性チェック
  - デッキ枚数
  - 同名カード枚数
  - 殿堂・プレミアム殿堂
  - 特殊な構築条件
- デッキ変更履歴
- バックアップ / 復元

### 1人回し
- 山札
- 手札
- マナゾーン
- バトルゾーン
- 墓地
- シールド
- 基本的なターン進行
- 進化元などカードの重なりを扱える構造

### ルール・裁定の下準備
Ver.1ではジャッジAIそのものは作らず、Ver.2で使う基盤を用意する。

- 基本ルールDB
- 裁定DB
- 公式Q&A・裁定情報
- 出典
- ルールバージョン
- 確認日
- カード本体と裁定データを分離
- 1枚のカードに複数の裁定を紐付け可能にする
- 裁定変更履歴

### 将来用データ構造の下準備
- 対戦記録の形式
  - 使用デッキ
  - 相手デッキ
  - 勝敗
  - 先攻 / 後攻
  - 日時
  - 対戦メモ
- カード履歴
  - 再録
  - テキスト変更
  - 裁定変更
  - 殿堂状態の変更

## Ver.2

最終目標：不快感のない良い対戦を作る。

- AI対戦
- 環境デッキ
- 必要に応じてモチーフデッキ
- 正確なゲーム進行
- 対戦結果保存
- ジャッジAI

### ジャッジAI

ゲーム状態、カードデータ、基本ルール、裁定DB、公式出典を使って判断する。

根拠を確認できない場合は、推測で裁定を作らず「公式裁定を確認できない」と返せる設計にする。

## Ver.2.5

- 指定ユーザーへの公開
- ユーザー管理
- 公開範囲管理
- 新カード対応
- 新カードを確認次第カードDBへ追加
- 重複・欠損確認
- 将来的な新カード追加支援の下地

### 完全カードDB・高級版 / 特殊仕様対応

同じカード名でも、通常版と高級版・特殊仕様を別の「版」として管理できるようにする。

- 通常版
- 神アート
- 金トレジャーを含む各種トレジャー
- プロモ
- シークレットなどの特殊レア仕様
- イラスト違い
- ホイル / 加工違い
- 再録版
- 収録弾・商品
- カード番号
- 同名カード同士の紐付け
- ルール上の同一カード判定と、版情報を分離して管理

### コレクション・デッキ表示連携

- 所持カード / 所持枚数の管理
- 所持している版の管理
- お気に入り版の設定
- 未所持版の確認
- 同一カードの版違い一覧
- デッキ内でどの版を使用しているか指定
- 通常版2枚 + 神アート1枚 + 金トレジャー1枚のような混在構成に対応
- デッキ内容そのものと見た目・版指定を分離して管理

### カード検索・表示

- 通常版を含むすべての版を表示
- 神アートのみ表示
- トレジャー系のみ表示
- プロモのみ表示
- 高レア / 高級仕様のみ表示
- 同名カードから版違いへ移動できるUI

将来的には、所持カードだけでデッキの見た目を整えたり、高級版中心の構成を提案するAI機能にも接続できる設計にする。

## Ver.3

最終目標：対戦結果を使って、より良い対戦ができるデッキへ改善する。

- 対戦結果分析
- 弱点分析
- カード変更提案
- カード入れ替え
- デッキ方向性提案
- 変更前後の比較
- 勝てるところまで調整を繰り返す
- デッキ変更履歴と対戦結果を関連付ける

## バグ・不具合対応AI

Ver.3までに、バグや不具合へ素早く対応できるAIを組み込むことを目標とする。

- 不具合検出
- エラー確認
- 原因特定
- 影響範囲確認
- 修正案作成
- 修正後の動作確認
- 必要なら再修正

## 現在の最優先事項

1. 全カード対応できるカードDB基盤を作る
2. カード情報の正確性を確認する
3. 全カード検索・表示を安定させる
4. レッドゾーン関連5枚で基準テストを行う
5. その後、Ver.1の1人回しへ進む

## 最終的な方向性

単なるデッキ管理アプリではなく、

- カードを調べる
- デッキを作る
- ルールや裁定を確認する
- 1人回しをする
- AIと対戦する
- 対戦結果を分析する
- デッキを改善する
- バグや不具合を素早く直す

ところまで支援する、デュエル・マスターズ総合サポートアプリを目指す。
